# 관리자 개선 체크리스트

상태 기준: 수정과 검증을 구분한다. 브라우저 테스트는 가상 데이터이며 운영자 화면의 최종 사용자 확인을 대체하지 않는다.

| 항목 | 1차 반영 | 검증 / 2차 확인 |
| --- | --- | --- |
| 2-1 수료 메일 선택 | 기본 해제된 체크로 선택, 서버도 명시적 선택 없으면 차단 | 발송 함수 모의 테스트 통과. 실제 메일 발송은 하지 않음 |
| 2-2 주민등록번호 수정 | 편집 중 번호 수정, 서버 암호화 및 중복 번호 차단 | DB 롤백 테스트/입력창 테스트 통과. 원본 번호는 자동 노출하지 않음 |
| 2-3 저장/취소 아이콘 | 편집 중 메뉴 대신 바로 표시 | 브라우저 버튼 노출 확인 |
| 2-4 신청 추가/변경 | 메뉴에 추가/변경 창, 변경 이력과 최초 접수 시각 유지 | 다른 회차 추가/변경 DB 검증 통과. 동일 회차 중복은 기존 UNIQUE 제약 유지, 변경 승인 대기. 수료/발급 이력 건은 변경 금지 |
| 2-5 신청 과정 → 과정조회 | 해당 신청 행 이동/강조 | 운영 화면 필터 조합별 확인 필요. 대기/거절/취소는 과정조회 대상 아님을 안내 |
| 3-1 수료 메일 선택 | 일반/A·B 모두 기본 미발송 | 2-1과 동일 |
| 3-2 A·B 팝업 | 수료 선택 및 기존 수료 버튼 재클릭, 기존 체크 표시 | 팝업/취소/재열기/미체크 차단 테스트 통과. 과정 has_parts 설정 필요 |
| 3-3 이름 → 신청현황 | 해당 신청자 행 이동/강조 | 운영 화면 필터 조합별 확인 필요 |
| 4-1 개별 일정 | 렌더 시 즉시 버튼 연결 및 초기화 보완 | 최초 표시/재렌더/클릭/중복방지 테스트 통과 |
| 4-2 회차 편집 UI | 입력항목 이름 표시, 2열/모바일 1열, 하단 저장/취소 | 입력 레이블 생성 확인. 실제 화면 디자인 사용자 확인 필요 |
| 5-1 1과목/2과목 서식 | 실제 수료한 과목 수로 줄 수와 훈련기간 위치 분기 | 단위 테스트/PDF 생성 회귀검사 통과 |
| 5-2 원본 서식 유사성 | 원본 HWP 미리보기와 대조하여 제목 자간·위치, 발급기관/대표이사 문구 폭·행간 보완 | 생성 PDF 시각 검토 완료. 원본 글꼴·테두리까지 완전히 동일한 복제는 아님 |
| 5-3 항목 간격 | 레이블/콜론/값 시작점, 42pt 간격 및 두 과목 추가 줄 정렬 | 실제 생성 PDF 렌더 확인 |

## 주의사항

- 2026-09-12: A/B 수료 설정을 중앙 모달로 변경하고 수료 버튼 스타일 통일. 수료 요약은 과정 → 과목 → 회차로 구분. 13개 단위 테스트와 모의 브라우저 저장/취소/모바일·PC 중앙 배치, PDF 생성 검증 통과.

- 과정 변경은 기존 신청 상태와 접수 시각을 유지하며 A/B 체크는 초기화한다. 변경만으로 메일을 발송하지 않는다.
- 주민등록번호 수정은 즉시 별도 저장되며, 일반 정보 편집 취소와 별개이다.
- 동일 회차 중복 제약 완화는 안전 검토에서 차단되어 적용하지 않았다. 사용자 범위 확인 후 재검토한다.
- 수료 알림 서버는 관리자 인증을 확인하며, 수료 선택 발송은 메일만 요청하고 문자는 보내지 않는다.
